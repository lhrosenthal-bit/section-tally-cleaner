
 Section Tally Cleaner

This project is part of the **Academic Admin Tools** organization.

It provides a simple, web-based tool for cleaning and standardizing section tally spreadsheets used in academic reporting and decision-making.

## Purpose

Section tally files are often exported in inconsistent formats that require significant manual cleanup before they can be used for analysis, sharing, or reporting.

This tool turns that recurring cleanup process into a repeatable, transparent workflow.

## What the tool does

The Section Tally Cleaner:
- Extracts semester information embedded in the file
- Removes extraneous rows, images, and empty columns
- Normalizes formatting for consistent downstream use
- Produces a clean, analysis-ready spreadsheet

The goal is not to replace institutional judgment, but to reduce unnecessary manual labor and make the underlying data easier to work with.

## How it’s used

The app is built with Streamlit and runs locally in a web browser.
Users upload a section tally spreadsheet and download a cleaned version that follows a consistent format.

## Context

This project reflects a broader approach to academic administration:
turning recurring institutional tasks into systems that are clear, reusable, and easier to maintain over time.
